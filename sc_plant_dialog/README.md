# Auto Plant & Splice - In-Game Growtopia Dialog Edition

Script otomatisasi tanam (Plant) dan kawin bibit (Splice) untuk Growlauncher Android & PC yang **100% menggunakan In-Game Dialog asli Growtopia**.

## Keunggulan Versi Ini:
1. **Bukan UI Native**: Tidak menempel di drawer/sidebar menu Growlauncher.
2. **Bukan UI Console ImGui**: Tidak ada jendela floating ImGui di layar.
3. **100% In-Game Dialog**: Menggunakan jendela pop-up dialog asli engine game Growtopia (`OnDialogRequest`).
4. **Ketik Sangat Lancar di Android**: Karena menggunakan dialog resmi game, keyboard virtual Android/HP otomatis terbuka sempurna tanpa bug dobel huruf atau kursor macet.
5. **Command `/plant`**: Cukup ketik `/plant` (atau `/p` / `/boren`) di kotak chat game Growtopia kapan saja untuk membuka atau memperbarui form.

## Cara Menggunakan:
1. Buka Script Manager di Growlauncher.
2. Pilih file `auto_plant.lua` di folder `sc_plant_dialog/`.
3. Klik **Run / Execute**.
4. Form dialog resmi Growtopia akan langsung muncul di layar game Anda!
5. Kapan pun Anda ingin membuka kembali form, cukup ketik:
   ```text
   /plant
   ```
